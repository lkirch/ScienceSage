# Demo Data for ScienceSage

This directory contains small, static datasets for reproducible demos and tests.

## Files
- `demo_chunks.json`: Example input chunks/questions and answers.
- `demo_feedback.csv`: Example user feedback for demo queries.
- `demo_ground_truth.csv`: Example ground truth answers for evaluation.

## Usage
- Use these files with scripts and tests by specifying the path or using a `--demo` flag (to be implemented).
- Ensures consistent, reproducible results for demos and CI.
